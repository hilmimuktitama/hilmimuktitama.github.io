# Image generation briefs

These are condensed records of the prompts used for the three independent built-in Image Gen calls. The complete literal prompts remain in the task. All calls requested a natural 1440 × 1120 desktop website canvas, one proposal per image, and used 2026-09-05 as the date anchor. The generated PNGs retain the tool's original dimensions.

## Shared brief

Redesign Hilmi Muktitama's personal website around the real writing of a Senior Technical Program Manager at Mekari. Help readers and potential collaborators understand his thinking, find professional experience, and inspect public experiments. The user rejected the generic visual character of the existing draft.

Use the existing paired light/dark board and live dark homepage screenshot as identity and content references, not as a visual target. Depart from the oversized condensed slogan, cobalt band, coral emphasized word, and numbered principle columns. Generate three structurally and visually distinct proposals, not three color variants.

Use intentional typography, realistic reading sizes, generous spacing, no more than two type families per proposal, and one primary reading action. Do not invent metrics, testimonials, portraits, project screenshots, employment facts, or adoption claims. Do not add card grids, generic dashboard controls, gradients, glass effects, or UI features merely to fill space. No device frames, browser chrome, concept labels, or multiple designs within one image.
